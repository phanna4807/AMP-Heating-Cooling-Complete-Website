AMP Heating & Cooling — GitHub Pages website + email setup

Upload all files to the ROOT of your GitHub repository (index.html beside assets/).
In assets/script.js, set AMP_FORM_RECIPIENT to the real receiving email.
Then follow START_EMAIL_SETUP.txt to activate FormSubmit and test both emails.
Until the receiving address is configured and verified, the forms remain PREVIEW-ONLY.
The chat assistant is still a prewritten FAQ demo, not live AI.
GitHub Pages cannot run PHP; forms use a third-party email service.
