AMP HEATING & COOLING — GITHUB PAGES + VS CODE

This is a complete, seven-page STATIC WEBSITE PREVIEW with a responsive design.

OPEN IN VS CODE:
1. Extract this ZIP into a new folder.
2. VS Code > File > Open Folder > choose the extracted folder.
3. Right-click index.html > Open with Live Server (install Live Server extension if needed).
   Or simply double-click index.html to preview in a browser.

PUBLISH TO GITHUB PAGES:
1. Open the root of your AMP-Heating-Cooling GitHub repository (branch main).
2. Add file > Upload files.
3. Open THIS extracted folder, select the seven .html pages AND the assets folder,
   and upload them to the repository root (not into another nested folder).
4. Commit changes.
5. Settings > Pages > Deploy from branch > main > /(root) > Save.
6. Wait for deployment, then visit:
   https://phanna4807.github.io/AMP-Heating-Cooling/
7. Press Ctrl+Shift+R to force-refresh if older styles are cached.

IMPORTANT LIMITATIONS:
- FAQ chat is a local demonstration, NOT a live AI API assistant.
- Forms prepare a copyable summary, but do NOT send or email any requests.
- GitHub Pages cannot execute PHP or secure OpenAI API keys.
- To accept live customer requests, send confirmation emails, have an employee dashboard,
  or add live AI, you will need a hosted backend and appropriate configuration.
- Never publish passwords, API keys, or confidential customer data to GitHub.
